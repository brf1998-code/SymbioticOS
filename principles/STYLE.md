# Visual style

One visual language across every module page.

- System font stack (`system-ui, sans-serif`). Background `#f2f4f7`, cards white with `1px solid #d5dbe3`, radius 10px.
- Ink `#1c242e`, secondary text `#51606f`.
- Status colors: running/good `#2e7d4f`, attention `#c2620a`, stopped/bad `#b3261e`, actions/navigation `#1f3a5f`.
- Status pills: bold white text on the status color, rounded.
- Type scale: page title ~21px, section ~15px, body 13px, meta 11.5px. Operator station pages go bigger: the main action and the current job are readable at arm's length on a phone.
- Touch targets at least 44px on operator-facing controls.
- Tables: header row in 11px uppercase steel, rows separated by the line color.
- No decorative elements. Density over whitespace on operator boards; a board is read from ten feet away.
